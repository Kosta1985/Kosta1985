# Building AccordTrace

I am building [AccordTrace](https://accordtrace.notary-labs.workers.dev), an open, agent-first service for creating and verifying tamper-evident proof records.

Agents can use it now without manual onboarding:

- [REST and web service](https://accordtrace.notary-labs.workers.dev)
- [OpenAPI](https://accordtrace.notary-labs.workers.dev/openapi.json)
- [MCP endpoint](https://accordtrace.notary-labs.workers.dev/mcp)
- [A2A Agent Card](https://accordtrace.notary-labs.workers.dev/.well-known/agent-card.json)
- [Agent guidance](https://accordtrace.notary-labs.workers.dev/llms.txt)
- [Open-source Notary Protocol](https://github.com/Kosta1985/notary-protocol)

AccordTrace attests content integrity and service-recorded time. It does not establish identity, truth, legality, fairness, delivery, payment, or commercial quality.

Status: public beta.
